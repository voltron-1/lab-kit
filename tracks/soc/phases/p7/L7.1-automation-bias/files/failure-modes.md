# Human-Automation Failure Modes
- **commission**: Acting on a wrong automated action/verdict without verifying.
- **omission**: Missing an incident because the automation did not flag it.
- **complacency**: Stopping spot-checks on a system assumed to be "always right".
- **deskilling**: Losing the ability to triage manually when automation is unavailable.
- **anchoring**: Accepting the AI's initial guess before reading the raw evidence.
